# Spécifications fonctionnelles

Une spec par fonctionnalité, nommée `<epic>-<sujet>.md` (ex. `planification-ajout-etape.md`), à partir
du [modèle](_template.md). Pour en rédiger une avec Claude : `/new-spec <fonctionnalité>`.

Cycle de vie : **Brouillon** → **Validée** (par l'utilisateur) → **Implémentée**. On n'implémente
qu'une spec validée.
