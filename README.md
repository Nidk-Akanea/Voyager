# Voyager

Préparer un voyage, puis le raconter : Voyager réunit la planification (itinéraire, étapes,
réservations, budget) et le carnet de voyage (notes, photos, carte) autour d'un même modèle.

> Projet en phase de cadrage : pas encore de code applicatif, la stack n'est pas choisie.
